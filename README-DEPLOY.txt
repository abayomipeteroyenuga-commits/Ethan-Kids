ETHAN KIDS — STANDALONE DIRECT ACCESS

This ZIP contains ONLY the Ethan Kids website, with index.html at the ZIP root.
Deploy its extracted files to the GitHub repository connected to the Vercel project for kids.ethandigitalacademy.org.
Vercel: Framework Preset = Other; Root Directory = repository root; Output Directory = leave blank.
Visit https://kids.ethandigitalacademy.org — index.html opens the activities directly.
No Ethan Hub, Ethan ID, Supabase, adult account, or SSO is required.
Activities and progress are stored locally in the visitor's browser; they are not synchronized across devices.
For younger children, adult supervision is recommended.
This build is publicly accessible: do not use it to store private student information.
