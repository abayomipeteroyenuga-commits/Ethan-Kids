# Ethan Kids v14 — PWA Install & Deployment

1. Upload the contents of this ZIP to the root of the Ethan Kids GitHub/Vercel project. Do not upload the enclosing ZIP folder as a nested folder.
2. Deploy to an HTTPS domain. PWA installation and service workers require HTTPS, except on localhost for testing.
3. Open the site and use **Install Ethan Kids**. Chromium browsers can show a native prompt. On iPhone/iPad, open the site in Safari, tap Share, then **Add to Home Screen**.
4. Visit the learning pages once while online so their pages/assets can be cached for offline use.
5. Test navigation, install behavior, offline mode, authentication and safeguarding before public launch.

PWA readiness does not mean the site has been deployed, that every external service works offline, or that authentication has been fixed.
