Audited v11 source: 26 HTML pages. Findings: brand absent from header, Ethan Code artwork used as structured-data/social brand image, long crowded learning-world menu, inconsistent subject identity across pages, older activity pages without unified banner, and no skip-to-content link.

Implemented: new clearly labelled **provisional Ethan Kids wordmark** (not the original official logo); consistent header branding on all 26 pages; corrected social/structured-data branding references; subject-specific illustrations and palettes across 22 modern hero pages and identity strips on 4 older pages; clearer three/two/one-column learning menu; active-page highlighting; skip link and main landmark target; responsive and reduced-motion styling. No external image hotlinks, trackers, or changes to existing learning JavaScript. SEO canonical URLs and sitemap preserved.
