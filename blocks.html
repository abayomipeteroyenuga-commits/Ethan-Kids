Block Coding

Sequence, repeat, decisions and events. Learn one idea, practise it, solve a mission and explain your thinking.

Explore the modules ↓
🧩

How to learn here

Discover → Try → Solve → Create → Explain. Each module includes a clear idea, a practical example and a mission. Take your time; mistakes help you improve.

Explore 5 learning modules

MODULE 01

Sequence

Put instructions in the right order so a character reaches its goal.

Try it: Move right twice, then move down.

Remember: A sequence runs one step after another.

MODULE 02

Loops

Use repeat when the same action happens several times.

Try it: Repeat move right 3 times.

Remember: Loops make instructions shorter and easier to change.

MODULE 03

Conditions

Choose an action when a condition is true.

Try it: If the path is blocked, turn left.

Remember: A condition helps a program decide.

MODULE 04

Events

Start an action when something happens.

Try it: When the star is clicked, say Hello.

Remember: Events respond to a click, key or other trigger.

MODULE 05

Debugging

Find a mistake, predict a fix and test again.

Try it: A robot moves too far: change repeat 4 to repeat 3.

Remember: Debugging is checking what happened and improving the instructions.
