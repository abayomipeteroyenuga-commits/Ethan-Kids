Color & Character Lab

Explore the meaning of color codes, learn useful coding symbols and make designs that are easy to read.

☀️
🖍️
🎨
✦   ✳   ✦
Mix colors and decode symbols

1 · Color Explorer

Colors can be named (green), written as HEX (#008080), or as RGB (rgb(0, 128, 128)). The # starts a hexadecimal color code; each pair of digits controls red, green and blue. Digits use 0–9 and A–F.

HEX #008080 · RGB 0, 128, 128

Try: Choose a color for a school website. Would dark text or light text be easier to read on it?

2 · Color families

Primary colors in light are red, green and blue (RGB). Mixing light is different from mixing paint. Warm and cool color groups can help organize a design.

Mission: Make a three-color palette with one main color, one accent and one background.

3 · Readable designs

Text must be easy to read against its background. Try a dark text color on a pale background and compare it with pale text on a pale background.

Mission: Design a button that is easy to spot and read.

4 · Character Lab

# starts a CSS ID selector or HEX color; . starts a CSS class selector; < > surround HTML tags; { } hold CSS rules and JavaScript blocks.

Mission: Find the different jobs of # in #title and #00aa88.

5 · More symbols

( ) group function inputs, [ ] access list items, " " wrap text, = assigns a value, and === checks strict equality in JavaScript.

Mission: Explain what changes between let score = 3 and score === 3.
