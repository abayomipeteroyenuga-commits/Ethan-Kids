Internet & Computer Systems Lab

Learn how devices, browsers, websites and files work using safe interactive models.

LESSON 1 OF 5

Devices and software

Hardware is the physical equipment. Software gives a device instructions. A browser is software that displays websites.

Try it: Sort a keyboard, browser, screen and game into hardware or software.

Stretch challenge: Explain how a device and a browser work together.

LESSON 2 OF 5

Web addresses

A web address helps a browser locate a website. A domain is one part of an address; a page path can identify a specific page.

Try it: Identify the domain and page path in a sample address.

Stretch challenge: Build a pretend address from its parts.

LESSON 3 OF 5

Requests and responses

A browser requests a page; a server sends a response. The browser then displays the page to you.

Try it: Put browser request, server response and display in order.

Stretch challenge: Explain the journey of a page in three steps.

LESSON 4 OF 5

Files and folders

Files store information and folders help organise them. A descriptive filename makes a project easier to find.

Try it: Organise three pretend project files into folders.

Stretch challenge: Plan a folder for a small website.

LESSON 5 OF 5

Privacy and checking

Not everything online is correct. Avoid sharing personal information and ask a trusted adult when unsure.

Try it: Compare a claim with another reliable source.

Stretch challenge: Make a three-question checklist for safe browsing.
