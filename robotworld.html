Robot World

Guide a friendly robot using directions, sequences, loops and debugging.

Start learning ↓

LESSON 1 OF 5

Directions

A robot needs exact instructions. Up moves one square toward the top; right moves one square across. Predict where each command will take it.

Try it: Try a route with two commands, then compare your prediction with the robot’s position.

Stretch challenge: Plan a route to the star using no more than six commands.

LESSON 2 OF 5

Sequences

The order of commands matters: up then right is not the same journey as right then up when obstacles are present.

Try it: Write a sequence and explain why you chose its order.

Stretch challenge: Reach the star without touching a wall.

LESSON 3 OF 5

Loops

A loop repeats a group of instructions. Instead of writing RIGHT four times, we can say REPEAT 4 RIGHT.

Try it: Find a repeated movement in your route.

Stretch challenge: Complete a route with fewer written commands.

LESSON 4 OF 5

Decisions

A condition chooses an action based on what is true: IF the square ahead is blocked, turn.

Try it: Explain what a robot should do when a path is blocked.

Stretch challenge: Create two routes for two different obstacle maps.

LESSON 5 OF 5

Debugging

A bug is a mistake in instructions. Check the first place your prediction differs from the result and fix one step.

Try it: Run a route, find the first wrong step, and change it.

Stretch challenge: Reach the star, then improve the route.
